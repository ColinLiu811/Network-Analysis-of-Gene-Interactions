# Examples

This directory contains standalone scripts and notebooks that demonstrate
common project workflows.

## Scripts

- `basic_pipeline_example.py` - simple scripted pipeline execution template
- `compare_networks_example.py` - compare two graph files with overlap/stats
- `identify_drug_targets_example.py` - shortlist top hub candidates
- `validation/stability_analysis.py` - run-to-run hub/score stability checks
- `validation/run_metadata_capture.py` - capture environment/file run metadata

## Notebooks

- `notebooks/interactive_tutorial.ipynb` - beginner walkthrough
- `notebooks/example_analysis.ipynb` - practical exploratory analysis
- `notebooks/validation_stability.ipynb` - validation and reproducibility checks
