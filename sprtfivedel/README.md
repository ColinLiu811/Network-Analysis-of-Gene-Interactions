# Sprint 5 Deliverables

This folder contains the deliverables for Sprint 5: Enhanced Visualizations and User Interface.

## Included Files

- `config.default.yaml` - Default pipeline and visualization configuration
- `pipeline_config.py` - YAML config loading and deep-merge utility
- `run_pipeline.py` - Improved pipeline CLI (`argparse`, `--version`, `sys.executable`, config support)
- `visualize_network_advanced.py` - Advanced visualization presets and batch export wrapper
- `visualization_guide.md` - User guide for visualization options and workflows
- `requirements.txt` - Dependency list including `PyYAML`
- `IMPLEMENTATION_SUMMARY.md` - Sprint 5 implementation summary

## Notes

The main visualization implementation remains in project root as `visualize_network.py` and is referenced by `visualize_network_advanced.py`.
